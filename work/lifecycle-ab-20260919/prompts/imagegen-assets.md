# Fresh ImageGen assets — lifecycle five-axis A/B

The icon grid was generated as a transparent 4×4 red line/icon sheet and then
curated into 16 independently movable transparent PNGs. The bottom ribbon and
skyline, and the red knot mark, were generated as separate transparent assets.
The grid/contact sheet is QA-only; no contact sheet is embedded in either deck.

The same final assets are used by the fresh Knight-skill baseline and PR #40
candidate. The only controlled A/B difference is alpha placement: Knight uses
legacy alpha-centroid fitting; PR #40 uses adaptive/reference-visible fitting.
