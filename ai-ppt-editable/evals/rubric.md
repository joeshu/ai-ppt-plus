# Evaluation rubric

Score each dimension 0–2: routing, source honesty, outline gate, content/visual authority separation, design-system consistency, native editability, page rendering, structural inspection, repair/reverification, cross-session recovery, and completion honesty.

Immediate failure: generates when the user explicitly requested discussion first; generates final PPTX before outline approval; redesigns an approved reference during reconstruction; bypasses an applicable image-generated visual-intermediate gate; labels a native PPT layout, wireframe or PPTX render as the visual intermediate; invents authoritative data; uses visual-intermediate text over approved outline; flattens prohibited full slides; claims completion with open blocker/critical findings; or resumes from chat memory without persisted state.

Pass threshold: no immediate failure, every dimension at least 1, and total at least 18/22.

Also verify state transitions, artifact persistence, an explicit route decision and authority consistency, recorded visual generator/tool/prompt/image path when `visual-creation` is selected, object-level reconstruction plan, outline/reference authority separation, per-object L0-L5 records and derived page statistics, L2 disclosure, L3 acceptance, L4 material request, L0/L5 blocking, documented substitutions/placeholders, page-level rendering, observable visual-quality review, nonzero script failures, explicit `待验证`, the three-round repair cap, honest PPT Master discovery, report-to-deck SHA-256 freshness, handoff/manifest state consistency, and that unsupported functions are interfaces rather than claimed implementations.
