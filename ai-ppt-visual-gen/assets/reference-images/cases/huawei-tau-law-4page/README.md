# Huawei Tau Law — 4-page visual case

Case ID: `huawei-tau-law-4page`

This is a user-approved exemplar produced with `ai-ppt-visual-gen` on 2026-08-30. It demonstrates a high-end, commercial-safe, information-dense technology strategy deck in 16:9. The case is useful for planning semiconductor, systems engineering, infrastructure and other executive technology narratives.

## What to learn

- **Deck language**: obsidian graphite, brushed titanium, copper traces, restrained signal red and electric cyan.
- **Grid**: stable title baseline and 12-column editorial rhythm with page-local closure; no universal footer.
- **Material**: dark engineered surfaces, fine linework, controlled glow and precise alignment.
- **Density**: rich information hierarchy with one dominant visual relationship per page.
- **Framework progression**: hero thesis → dual-scale comparison → exploded cross-layer system map → evidence matrix and long-horizon route.
- **Commercial safety**: no logo, watermark or unlicensed external asset; content and data are not reusable from this case.
