# Bundled visual reference cases

This directory contains reviewed, user-approved visual cases for `ai-ppt-visual-gen`.

Use a case as visual guidance only. The image is not formal-copy authority:

- preserve the declared composition, hierarchy, density, material language and reading path when the case is selected;
- do not copy the case's text, numbers, logos, brand identity, citations or distinctive proprietary assets;
- default treatment is `layout-only`; `layout-and-style` is allowed only for a user-approved case and still excludes content reuse;
- keep the case's original raster files unchanged and record the selected case ID in the active visual plan.

Available cases:

- `cases/huawei-tau-law-4page/` — premium dark technology-strategy deck with four distinct page frameworks.
